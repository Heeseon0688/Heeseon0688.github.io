# Heeseon Im — Portfolio

[포트폴리오 보기](https://heeseon0688.github.io/)

임베디드 시스템, AI, 애플리케이션 개발 경험과 연구를 소개하는 개인 포트폴리오입니다.
미드나이트·시안을 기본 화면으로 사용하며, 테마 버튼으로 화이트·코발트 라이트 모드로 전환할 수 있습니다. 방문자가 마지막으로 선택한 모드를 기억합니다. 한국어/영어 전환, 프로젝트 필터와 실제 발표 자료를 볼 수 있는 사진 갤러리를 제공합니다.

## 로컬 미리보기

별도 빌드나 패키지 설치 없이 실행할 수 있습니다.

```sh
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`에 접속합니다.

## 수정

- `index.html`: 소개, 프로젝트, 연구, 경력과 링크. `data-ko`와 `data-en`에 두 언어의 문구를 함께 수정합니다.
- `style.css`: 색상, 레이아웃과 반응형 디자인.
- `script.js`: 언어·테마 전환, 프로젝트 필터와 모바일 메뉴.
- `assets/`: 첫 화면·연구용 그래픽과 파비콘.
- `assets/projects/`: 프로젝트 README의 발표 슬라이드에서 가져온 실제 이미지와 작은 미리보기. 원본 비율과 내용을 유지해 웹용 JPEG로 저장했습니다.
- `assets/projects/sources.json`: 이미지별 원본 URL과 출처 저장소.

프로젝트 사진을 선택하면 대표 이미지가 바뀌며, 큰 사진을 누르면 확대 뷰어가 열립니다. 뷰어에서는 좌우 화살표와 키보드 방향키로 이동하고 Esc로 닫을 수 있습니다. GitHub 카드와 하단 링크는 해당 프로젝트의 소스 코드·백엔드·전체 발표 자료로 연결됩니다.

`main` 브랜치에 반영하면 GitHub Pages에서 자동 배포됩니다.
